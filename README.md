# pysharpie

Current ported version: v0.5.2

This is a partial port of [Sharpie](https://github.com/orionarts/sharpie) to python, which was in turn derived from [SpringSharp](http://www.springsharp.com/). 

All ship calculations have been ported. Not ported over: load/save/convert functionality, gui, and any utility functions exclusively for the gui.
